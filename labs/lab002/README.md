# Лабораторная работа: Расчёт подсетей IPv4

## Проблема 1

### Исходные данные

- **IP-адрес узла:** `192.168.200.139`
- **Исходная маска подсети:** `255.255.255.0` (`/24`)
- **Новая маска подсети:** `255.255.255.224` (`/27`)

### Расчёт

**Количество бит подсети:**

Новая маска `/27`, исходная `/24`.

`27 - 24 = 3`

**Количество созданных подсетей:**

`2^3 = 8`

**Количество бит узлов в подсети:**

IPv4 содержит 32 бита.

`32 - 27 = 5`

**Количество узлов в подсети:**

Всего адресов:

`2^5 = 32`

Из них два адреса служебные: адрес сети и широковещательный адрес.

`32 - 2 = 30`

### Ответ

- **Биты подсети:** `3`
- **Количество подсетей:** `8`
- **Биты узлов:** `5`
- **Количество узлов:** `30`
- **Адрес подсети:** `192.168.200.128`
- **Первый IP-адрес узла:** `192.168.200.129`
- **Последний IP-адрес узла:** `192.168.200.158`
- **Широковещательный адрес:** `192.168.200.159`

### Метод определения адресов

Маска `/27` оставляет 5 бит для узлов. Размер одной подсети:

`2^5 = 32 адреса`

Диапазоны последнего октета идут с шагом 32:

`0–31`, `32–63`, `64–95`, `96–127`, `128–159` и т. д.

IP-адрес `192.168.200.139` находится в диапазоне `128–159`.

Поэтому:

- адрес сети — `192.168.200.128`;
- первый узел — `192.168.200.129`;
- последний узел — `192.168.200.158`;
- broadcast — `192.168.200.159`.

## Проблема 2

### Исходные данные

- **IP-адрес узла:** `10.101.99.228`
- **Исходная маска подсети:** `255.0.0.0` (`/8`)
- **Новая маска подсети:** `255.255.128.0` (`/17`)

### Расчёт

**Количество бит подсети:**

`17 - 8 = 9`

**Количество созданных подсетей:**

`2^9 = 512`

**Количество бит узлов:**

`32 - 17 = 15`

**Количество узлов:**

`2^15 = 32768` адресов

`32768 - 2 = 32766` узлов

### Ответ

- **Биты подсети:** `9`
- **Количество подсетей:** `512`
- **Биты узлов:** `15`
- **Количество узлов:** `32766`
- **Адрес подсети:** `10.101.0.0`
- **Первый IP-адрес узла:** `10.101.0.1`
- **Последний IP-адрес узла:** `10.101.127.254`
- **Широковещательный адрес:** `10.101.127.255`

### Метод определения адресов

При `/17` первые два октета и первый бит третьего октета относятся к сетевой части.

Третий октет IP:

`99 = 01100011`

Первый бит равен `0`. Для получения адреса сети все 15 бит узлов обнуляются.

Получаем:

`10.101.0.0`

Для получения широковещательного адреса все биты узлов устанавливаются в `1`.

Максимальное значение третьего октета в этой подсети — `127`, поэтому:

`10.101.127.255`

Последний адрес узла на единицу меньше:

`10.101.127.254`

## Проблема 3

### Исходные данные

- **IP-адрес узла:** `172.22.32.12`
- **Исходная маска подсети:** `255.255.0.0` (`/16`)
- **Новая маска подсети:** `255.255.224.0` (`/19`)

### Расчёт

**Количество бит подсети:**

`19 - 16 = 3`

**Количество созданных подсетей:**

`2^3 = 8`

**Количество бит узлов:**

`32 - 19 = 13`

**Количество узлов:**

`2^13 = 8192` адреса

`8192 - 2 = 8190` узлов

### Ответ

- **Биты подсети:** `3`
- **Количество подсетей:** `8`
- **Биты узлов:** `13`
- **Количество узлов:** `8190`
- **Адрес подсети:** `172.22.32.0`
- **Первый IP-адрес узла:** `172.22.32.1`
- **Последний IP-адрес узла:** `172.22.63.254`
- **Широковещательный адрес:** `172.22.63.255`

### Метод определения адресов

При `/19` первые 16 бит полностью занимают первые два октета, а ещё 3 бита берутся из третьего октета.

Третий октет:

`32 = 00100000`

Первые три бита:

`001`

Для адреса сети остальные биты узлов устанавливаются в `0`:

`00100000 = 32`

Получаем адрес сети:

`172.22.32.0`

Для определения верхней границы подсети 5 хостовых бит третьего октета устанавливаются в `1`:

`00111111 = 63`

Четвёртый октет также полностью относится к узлам.

Поэтому:

- broadcast — `172.22.63.255`;
- последний узел — `172.22.63.254`.

## Проблема 4

### Исходные данные

- **IP-адрес узла:** `192.168.1.245`
- **Исходная маска подсети:** `255.255.255.0` (`/24`)
- **Новая маска подсети:** `255.255.255.252` (`/30`)

### Расчёт

**Количество бит подсети:**

`30 - 24 = 6`

**Количество созданных подсетей:**

`2^6 = 64`

**Количество бит узлов:**

`32 - 30 = 2`

**Количество узлов:**

`2^2 = 4` адреса

`4 - 2 = 2` узла

### Ответ

- **Биты подсети:** `6`
- **Количество подсетей:** `64`
- **Биты узлов:** `2`
- **Количество узлов:** `2`
- **Адрес подсети:** `192.168.1.244`
- **Первый IP-адрес узла:** `192.168.1.245`
- **Последний IP-адрес узла:** `192.168.1.246`
- **Широковещательный адрес:** `192.168.1.247`

### Метод определения адресов

Последний октет IP:

`245 = 11110101`

При `/30` первые 6 бит последнего октета относятся к сети, а последние 2 — к узлам.

Для получения адреса сети последние два бита обнуляются:

`11110100 = 244`

Поэтому адрес сети:

`192.168.1.244`

Так как в `/30` всего 4 адреса, диапазон этой подсети:

`192.168.1.244 – 192.168.1.247`

Из них:

- `.244` — адрес сети;
- `.245` — первый узел;
- `.246` — последний узел;
- `.247` — broadcast.

# Контрольный вопрос

## Почему маска подсети важна при анализе IPv4-адреса?

Маска подсети определяет, какая часть IPv4-адреса относится к сети, а какая — к узлам.

Один из октетов IPv4-адреса может быть разделён между сетевой и хостовой частями. Поэтому без знания маски невозможно однозначно определить адрес подсети, диапазон доступных адресов узлов и широковещательный адрес.

# Основные формулы

Количество бит подсети:

`Новый префикс - исходный префикс`

Количество подсетей:

`2^(количество бит подсети)`

Количество бит узлов:

`32 - новый префикс`

Количество адресов в подсети:

`2^(количество бит узлов)`

Количество доступных адресов узлов:

`2^(количество бит узлов) - 2`

Широковещательный адрес:

`Адрес сети + количество адресов в подсети - 1`

Последний адрес узла:

`Широковещательный адрес - 1`
