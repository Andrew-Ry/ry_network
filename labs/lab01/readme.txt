# Лабораторная работа: Просмотр таблицы MAC-адресов коммутатора

## Цель работы

- Создать и настроить локальную сеть на базе коммутаторов Cisco.
- Настроить IP-адреса устройств.
- Изучить принцип формирования таблицы MAC-адресов коммутатора.
- Проверить изменение таблицы MAC-адресов после передачи данных между устройствами.
- Изучить связь между IP-адресами, MAC-адресами и портами коммутатора.

---

## Топология

В лабораторной работе использовались два коммутатора **S1** и **S2**, соединённые между собой.

К коммутаторам были подключены компьютеры локальной сети.

Дополнительно был добавлен компьютер с IP-адресом:

`192.168.1.3`

Все устройства находятся в одной подсети:

`192.168.1.0/24`

# Часть 1. Создание и настройка сети

## 1. Сборка топологии

В Cisco Packet Tracer была собрана локальная сеть из двух коммутаторов и компьютеров.

Коммутаторы S1 и S2 были соединены между собой Ethernet-соединением.

Компьютеры были подключены к портам коммутаторов.

Дополнительно к сети был подключён **PC-C** с IP-адресом:

`192.168.1.3`

---

### PC-B

# Часть 2. Изучение таблицы MAC-адресов коммутатора

## 1. Определение MAC-адресов устройств

Для просмотра информации о сетевых интерфейсах компьютеров использовалась команда:

```text
ipconfig /all
```

Она позволяет определить IP-адрес компьютера и физический MAC-адрес его сетевого интерфейса.

---

## 2. Просмотр MAC-адреса интерфейса коммутатора

На коммутаторах использовалась команда:

```text
show interface fastEthernet 0/1
```

В выводе команды можно увидеть MAC-адрес соответствующего физического интерфейса коммутатора.

---

## 3. Просмотр таблицы MAC-адресов

На коммутаторе S2 была выполнена команда:

```text
show mac address-table
```

Команда показывает MAC-адреса, которые коммутатор уже изучил, и порты, через которые доступны соответствующие устройства.

Коммутатор автоматически изучает MAC-адрес источника каждого полученного Ethernet-кадра и связывает этот MAC-адрес с портом, через который кадр был получен.

---

## 4. Очистка динамической таблицы MAC-адресов

Для удаления динамически изученных MAC-адресов была выполнена команда:

```text
clear mac address-table dynamic
```

После этого таблица была повторно проверена:

```text
show mac address-table
```

Динамические записи были удалены.

При появлении нового сетевого трафика коммутатор снова начал автоматически изучать MAC-адреса устройств.

---

## 5. Проверка сетевой связности

Для создания сетевого трафика между устройствами использовалась команда `ping`.

С компьютера отправлялись ICMP эхо-запросы другим устройствам сети.

Например:

```text
ping 192.168.1.1
ping 192.168.1.11
ping 192.168.1.12
ping 192.168.1.3
```

После обмена данными таблица MAC-адресов была просмотрена повторно:

```text
show mac address-table
```

В таблице появились динамически изученные MAC-адреса устройств.

---

## 6. Проверка ARP-таблицы

На компьютере была использована команда:

```text
arp -a
```

ARP-таблица содержит соответствия между IP-адресами устройств локальной сети и их MAC-адресами.

После выполнения `ping` в ARP-кэше появились записи об устройствах, с которыми компьютер обменивался данными.

---

## Принцип работы таблицы MAC-адресов

При получении Ethernet-кадра коммутатор анализирует MAC-адрес источника.

Если этого адреса ещё нет в таблице, коммутатор запоминает соответствие:

```text
MAC-адрес → порт коммутатора
```

После этого коммутатор проверяет MAC-адрес назначения.

Если MAC-адрес назначения уже известен, кадр передаётся только через соответствующий порт.

Если MAC-адрес назначения неизвестен, коммутатор отправляет кадр через остальные порты VLAN, кроме порта, с которого этот кадр был получен.

Таким образом, таблица MAC-адресов формируется автоматически в процессе передачи Ethernet-кадров.

## Вывод

В ходе выполнения второй части лабораторной работы была изучена таблица MAC-адресов коммутатора.

Были использованы команды:

```text
show interface fastEthernet 0/1
show mac address-table
clear mac address-table dynamic
ping
arp -a
```

Было проверено, что коммутатор автоматически изучает MAC-адреса источников Ethernet-кадров и сопоставляет их со своими портами.

После очистки динамической таблицы MAC-адресов записи удаляются, однако при появлении нового сетевого трафика коммутатор снова автоматически заполняет таблицу.

Также была изучена работа ARP-кэша компьютера, в котором хранятся соответствия между IP-адресами и MAC-адресами устройств локальной сети.
